# MERN Task Management System

A full-stack task management application built using MongoDB, Express.js, React.js, and Node.js.

## Features
- Create, update, delete tasks
- Task status tracking
- Due-date management
- Search functionality
- Responsive UI

## Tech Stack
Frontend:
- React.js
- HTML
- CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB

Deployment:
- Vercel
